# Skill: Daily Standup
Run after new_day.py, after clearing unlogged results and dev directives.
Output exactly this shape, conversationally:
1. **Day N, streak S, belt B.** One line of momentum ("Music DB is at 22/40 tracks").
2. **Today's task** (from backlog, status BRIEFED→IN_PROGRESS): title, which project it ships into, and the one-sentence "why this matters to the channel".
3. **Acceptance criteria** — verbatim from the task. He should be able to self-check.
4. **Time box** and the block plan (Study/Drill/Production split for this task).
5. **One focus note** pulled from KB: his weakest dimension or a recurring defect to watch today.
Never assign two tasks. If he asks for tomorrow's task, decline — today first.
