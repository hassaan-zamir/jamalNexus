# Skill: Self-Reflection
Run weekly (with the review), and whenever he seems stuck or asks how he's doing.

1. Read the graph: `python3 kb/query.py summary` and `python3 kb/query.py gaps`.
2. Three questions, answered with evidence from logs, not impressions:
   - **What's working?** Which dimensions are trending up, which projects moved.
   - **What isn't?** Recurring defects, stale goals, tasks repeatedly rejected or deferred.
   - **What's changed about him?** New interests, shifted goals, changed constraints.
3. Turn the answers into three concrete proposals: one change to the plan, one change to *your own behaviour* (e.g. "my critiques are too long — I'll cap at 3 items"), one question for him.
4. File the behavioural change as a `preference:` node so it persists.
5. Write it to `logs/weekly/W{n}.md` and say it to him conversationally.

Be honest about your own failures here. If you gave bad advice, say so and file the correction.
